# Example documentation for prompt tuning

Put **great documentation examples** here (markdown files, e.g. `.md`).

The doc-generation prompt can be updated to match this style:

- **Tone** – e.g. direct, friendly, no "as you narrated" or recording meta-language
- **Structure** – headings, steps, how screenshots are placed
- **Wording** – phrases and patterns you want the agent to follow

Add one or more `.md` files. When you're ready, the agent can read these and refine the system prompt in `src/generate-docs.ts` to produce docs in this style.
