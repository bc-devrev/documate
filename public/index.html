Documate

Record your product. Get documentation.

Recording

Run Documate with npm run ui (from Terminal or any shell). When you click Start recording, macOS will ask for Screen Recording and Input Monitoring — allow Node or Terminal. For speech in docs, add a Deepgram key in Settings and allow Microphone when prompted.

Checking…

Wait for Recording active, then use your product.

If status stays "Screenpipe up; check permissions": open System Settings → Privacy & Security. In Screen Recording and Input Monitoring, click + and add Node (e.g. /usr/local/bin/node or your nvm node) and/or Terminal, then restart recording.

If Stop says "No recording process", click Start over to kill any leftover Screenpipe process.

Download documentation

Start recording → use your product (⌘M to capture a screenshot) → Stop → Download. Screenshots may take ~30s after stop.
